# Files apply_cp_patches.sh copies into a CircuitPython tree.
#
#   <path in this repo><TAB><path in the CircuitPython tree>
#
# The runtime-neutral DSP is copied straight out of src/shared/ rather than
# duplicated here, so a change to the MicroPython/CPython builds cannot leave
# CircuitPython behind. It lands under CircuitPython's own top-level shared/,
# where `-I$(TOP)` makes `#include "shared/audioif_dynamics.h"` resolve exactly
# as it does in this repo.

# Included first by every src/shared/*.c that computes in float (audioif#79),
# so it has to travel with them. If it does not, the CircuitPython build
# fails to compile rather than quietly keeping its fused multiply-adds --
# which is the right failure, and the reason this is an include and not a
# flag somebody could forget to pass.
